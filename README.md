# Project Overview
A functional React application featuring usr authenticaltion , protected routing, and a custom UI componenent library.

## Features
- Authentication: Centralized management using AuthContext with automatic localStorage persistence.
- Protected Routing: Role-based navigation control using react-router-dom.
- UI Library: A set of reusable components (MyButton, MyInput. MySelect, MyLoader, Pagination) using CSS Modules.
- Data Logic: Advanced post management(sorting, filtering, pagination) powered by custom hooks (useSortPost, useFetching, usePagination).
  
  ## Tech Stack

  Core: React, TypeScript.
  Navigation: React Router DOM.
  Styling: CSS Modules.
